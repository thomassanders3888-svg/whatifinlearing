# What If In Learning — Mortgage Calculator

A beautiful, production-ready mortgage calculator built for clarity and insight.

**Live Demo**: https://whatifinlearing.com/mortgage-calculator

## Features

- Real-time calculations with instant feedback
- Principal & Interest breakdown
- Total interest, payoff date, and savings projections
- Interactive balance chart (Chart.js)
- Full amortization schedule with CSV export
- Extra payment impact analysis
- Mobile responsive with dark mode support
- Zero dependencies (Tailwind + Chart.js via CDN)

## Tech

- Single-file HTML (easy to host anywhere)
- Tailwind CSS via CDN
- Chart.js via CDN
- Fully client-side

## Deployment

This site is configured for GitHub Pages.

```bash
git init
git add .
git commit -m "Initial mortgage calculator"
git branch -M main
git remote add origin git@github.com:thomassanders3888-svg/whatifinlearing.com.git
git push -u origin main
```

Then enable GitHub Pages in repo settings (deploy from `main` branch / root).
